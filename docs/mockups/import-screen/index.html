Import a document from Dropbox or Google Drive

On the first step of a new document, under the drop area: two buttons. Pick files in Dropbox's or Google's own window, we copy them in, and the screen carries on exactly as it does after an upload. Nothing is kept about the person's Dropbox or Drive.

Mockup only. Nothing is built or connected. How it would work (unverified until built): Dropbox's Chooser hands back a short-lived download link for each file, and Google's Picker hands back file ids that we fetch with a read-only token used for that one import and never saved. Whether to use these or a full "connect your account" login is the first question at the foot of the page.

Questions and notes

  • Question 1, what to build: pickers only (recommended: no stored logins, smallest security surface, fits the server hold) or a connected account with saved access (more convenient, but we would store a token per person).
  • Question 2, who sees the buttons: everyone who can upload, or switched on per organisation (recommended: per organisation, off by default, so a business that uses neither never sees them).
  • What it needs: a Dropbox app key and a Google Cloud project with the Picker API. Only Daniel can create those accounts, and neither is set up.
  • Privacy line under the buttons: "We copy the files you pick. We don't keep a link to your Dropbox or Drive."
  • Not in this mockup: OneDrive and SharePoint (Constructive is on Microsoft 365, so probably the next ask), Word to PDF, folders.
  • Unverified: how each picker looks on a phone, Google's review time for the read-only scope, and the 50 MB limit (the real limit comes from the server settings).
